In [[Tibetan Relative Clauses]] it shows how to make relative clauses expressing *that* or *which* for <i class="p">direct objects</i> with <i class="y">པའི་</i> (པ་ + *connective particle* འབྲེལ་སྒྲ་), e.g. (the milk **that** I have to the cat).

There are two relative clause constructions that can work in pair, one expressing the same as the other but in reverse logical direction: 

| <i class="g">པར་</i>     | <i class="b">པས</i>་  |
| ------------------------ | --------------------- |
| པ་ལ་                     | པ་ + བྱེད་སྒྲ་        |
| *in order to X*, *for X* | *and for that reason* |

## Examples

བོད་ཡིག་སློབ་<i class="g">པར་</i>ང་ལྷ་ས་ལ་ཕྱིན་པ་ཡིན།
*I went to Lhasa <i class="g">in order to</i> teach Tibetan.*
<small>* With པར་ we can express intention in future, it's not tied to the past.</small>

བོད་ཡིག་བསླབས་<i class="b">པས་</i>ང་ལྷ་ས་ལ་ཕྱིན་པ་ཡིན།
*I teach Tibetan, <i class="b">and for that reason</i> I went to Lhasa.*
<small>* With པས་ it implies the clause already happened, so it's tied to the past.</small>

## Speaking

ཁྱེད་རང་གི་རོགས་པ་བྱེད་<i class="y">ནས་</i>ཐུགས་རྗེ་ཆེ། (more informal; with friends)
ཁྱེད་རང་གི་རོགས་པ་བྱེད་<i class="y">པ་ལ་</i>ཐུགས་རྗེ་ཆེ། (better)
