## ་་་ན་འགྲིག་གི་རེད་པས།

> Subject (བྱེད་སྒྲ་ / no བྱེད་སྒྲ་) + Volitional verb past + ན་འགྲིག་གི་རེད་པས།

> [!WARNING] Past
> The verb, when followed by ན་, must be in the **past tense**.

# ཐུབ་པ་

> Subject / Instrument བྱེད་སྒྲ་ + Volitional verb present + ཐུབ་

| ------- | ------------------------- | ------------------------------------------------------------------- |
| Future  |                           | ཐུབ་ཀྱི་རེད། ཐུབ་ཀྱི་མ་རེད།                                         |
| Present | ཐུབ་ཀྱི་ཡོད། ཐུབ་ཀྱི་མེད། | ཐུབ་ཀྱི་ཡོད་རེད། ཐུབ་ཀྱི་ཡོད་མ་རེད།<br>ཐུབ་ཀྱི་འདུག ཐུབ་ཀྱི་མི་འདུག |
| Past    | ཐུབ་བྱུང་། ཐུབ་མ་བྱུང་།   | བཐུབ་པ་རེད། ཐུབ་ཡོད་མ་རེད།<br>ཐུབ་སོང་། ཐུབ་མ་སོང།                  |

# དགོས་པ་

| --------------- | ------------------------------- | -------------------------------------------------------------------------- |
| Future          |                                 | དགོས་(ཀྱི་)རེད། དགོས་(ཀྱི་)མ་རེད།                                          |
| Present         | དགོས་(ཀྱི་)ཡོད། དགོས་(ཀྱི་)མེད། | དགོས་(ཀྱི་)རེད། དགོས་(ཀྱི་)མ་རེད།<br>དགོས་(ཀྱི་)འདུག དགོས་(ཀྱི་)མི་འདུག    |
| Past            | དགོས་བྱུང་། དགོས་མ་བྱུང་།       | དགོས་བྱུང་བ་རེད། དགོས་བྱུང་ཡོད་མ་རེད།<br>དགོས་བྱུང་སོང་། དགོས་བྱུང་མ་སོང་། |
| Present perfect |                                 | དགོས་བྱུང་འདུག དགོས་བྱུང་མི་འདུག                                           |

When used alone, and not as an auxiliary: ^d4e43d
- ང་ལ་འདི་དགོས། or ང་ལ་འདི་དགོས་ཡོད་།
- <i class="r">ཁྱེད་རང་ལ་འདི་དགོས།</i> (དགོས་ alone seems to be usable only for yourself) or ཁྱེད་རང་ལ་འདི་དགོས་ཡོད་རེད།
- ཁྱེད་རང་ལ་འདི་དགོས་པས། (but in the question form using དགོས་ alone sounds good) or ཁྱེད་རང་ལ་འདི་དགོས་ཡོད་པས།

# མྱོང་

| བདག་                | གཞན།                          |
| ------------------- | ----------------------------- |
| མྱོང་ཡོད། མྱོང་མེད། | མྱོང་ཡོད་རེད། མྱོང་ཡོད་མ་རེད། |

When asking questions about yourself, think of you will answer, you don't say ང་་་ཐུབ་ཀྱི་ཡོད་པས། but ང་་་ཐུབ་ཀྱི་ཡོད་རེད་པས།
- ང་རིག་མཐོ་པོ་དེ་འཛེག་ཐུབ་ཀྱི་ཡོད་རེད་པས།
- ཁྱེད་རང་གཏན་གཏན་རི་མཐོ་པོ་དེ་འཛེག་ཐུབ་ཀྱི་ཡོད་རེད།
