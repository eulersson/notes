1. Ensure the file is in iCloud Drive
2. Long-tap and **Share**
3. Select **Collaborate**
4. Instead of *Only participants can make changes* tap and select *Anyone with the link* and *Can view only*.
5. The link still has not been created, this is the step that tripped me, now you need to share that link to an app, what I do is tap **Safari** so it actually exports the link and then opens it in **Safari**, it can take a while, don't 
6. Now you can copy the link from the Safari URL.
7. If you want to retrieve the link later on, visit the file, long tap it and **Managed Shared File** and then **Copy Link**.

If you want to check all what you shared at the bottom of the Files app it shows "Recents", "Shared" and "Browser": you want to click "Shared".
