## སྔོན་ལ་ and གོང་ལ་ — Before

### Verbs

> ==🔵དགག་སྒྲ་== + ==🟣verb== (present) + ==🟡སྔོན་ལ་== / གོང་ལ་ + rest of the sentence

ཁ་ལག་==🔵མ་== ==🟣ཟ་== ==🟡སྔོན་ལ་==ལག་པ་འཁྲུད་ཀྱི་ཡོད།
“==🟡Before== ==🔵not== ==🟣eating==, I wash \[my\] hands”

In Tibetan, literally, we say *Before not doing something*, so it's **negated** as opposed to English.

It makes sense since the action **hasn't happened** yet.

The fact verb is in *usually* the **present** tense (some people might use **past** tense if referring to a past event)  might suggest the **emphasis** is more in the **moment** rather than the action.

> [!WARNING] Don't Set In Stone
> Sometimes you might also hear བཟས་བའི་སྔོན་ལ་ instead of མ་ཟ་སྔོན་ལ་

Some more features:
- Works with བྱེད་མེད་ལས་ཚིག་ verbs
	- ཁེ་ས་དགོང་དག་ང་==🟣གཉིད་== ==🔵མ་== ==🟣ཤོར་== ==🟡སྔོན་ལ་==་་་
- Not limited to one agent
	- ==🟢རྒན་ལགས་==(ཀྱིས་)འགྲེལ་བཤད་==🔵མ་== ==🟣སྐྱོན་== ==🟡སྔོན་ལ་== ==🟠ང་==མགོ་འཐོམ་སོང་།

> [!TIP]
> Remember that English has **past perfect** which we can use when translating the **second part of the sentence** if it happens to be before the point marked with སྔོན་ལ་ if it's in the past. 

ཁེ་སང་ནང་ལ་==🟢མ་སླེབས་སྔོན་ལ་==ཨ་མ་ལགས་སྐྱིས་བ==🔵ཞེས་མོག་བཟོས་གནང་བ་རེད།== 
“Yesterday, ==🟢when I reached home==, my mother ==🔵had prepared== delicious momos” 

#### Translation Choices

ད་གིན་ཁ་ལག་མ་ཟ་སྔོན་ལ་ལག་པ་འཁྲུད་ཀྱི་ཡིན།
- A moment ago, before *eating*, I washed my hands
- A moment ago, before *I ate*, I washed my hands
- I washed my hands a moment ago, before *eating* / *I ate*.
- *Having not eaten* — stays more literal.

### Nouns

> ==🔵noun== + ==🟡འབྲེལ་སྒྲ་== + ==🟣སྔོན་ལ་== + rest of the sentence

👀 No need for དགག་སྒྲ་

==🔵འཛིན་གྲྭ== ==🟡འི་== ==🟣སྔོན་ལ་== ང་གྲ་སྒྲིག་ཡག་པོ་བྱེད་ཀྱི་ཡོད།
“Before class, I prepare well.”

The order can be tweaked to shift the emphasis:

“One has to practice the Generation Stage before the Completion Stage”

| Tibetan                                                                       | Emphasis               |
| ----------------------------------------------------------------------------- | ---------------------- |
| ==🟡རྫོགས་རིམ་==གྱི་ ==🟣གོང་ལ་== ==🔵བསྐྱེད་རིམ་==གྱི་ཉམས་ལེན་བྱེད་དགོས་རེད། | ==🟣point in time==    |
| ==🔵བསྐྱེད་རིམ་== དེ་ ==🟡རྫོགས་རིམ་==གྱི་==🟣གང་ལ་==ཉམས་ལེན་བྱེད་དགོས་རེད།་  | ==🔵generation stage== |

### Non-Verbs

We don't construct སྔོན་ལ་ with ལ་་་ཡོད་ or ཡིན་, instead **we find another equivalent verb**, which we can select based on whether the sentence requires བྱེད་འབྲེལ་ལས་ཚིག or བྱེད་མེད་ལས: 
- Before I had kids ...
	- ==ང་ལ་==སྤུ་གུ་==🔴མེད་པའི་==སྔོན་ལ་་་
	- སྤུ་གུ་==🟢མ་སྐྱེས་==སྔོན་ལ་་་
- Before she was a nun ...
	- བཙུན་མ་མ་==🔴ཡིན་==སྔོན་ལ་་་
	- བཙུན་མ་མ་==🟢གནང་==སྔོན་ལ་་་ (volitional)
	- བཙུན་མ་མ་==🟢ཆགས་==སྔོན་ལ་་་ (involitional)

> [!WARNING] Don't Set In Stone
> You might still hear nominalised non-verbs:
> - ཁོང་དགོན་པ་ལ་==🟣མེད་པའི་==སྔོན་ལ་་་་ “Before ==🟣being== at the monastery ...”
