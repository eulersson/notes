##  Words for “Clear”

Previously I had learnt གསལ་པོ་ to say “clear”. I think I have to be careful in which context I use it. Because I think it is meant to be used on the context of having not clarity, having no difficulty in an undertaken process.

To use “clear” a a verb, that is, as to imply making it clean of any other elements, དྭགས་ seems to be used (verb form དྭགས་པ་ adjective དྲྭགས་མ་). It's great to see that the verb *to recover / get better (H)*  uses actually that same word.

## ཞེ་ས་ Shadows Meaning

I don't like using གནང་ in ཞེ་ས་ because if shadows the real meaning, forcing you to require more context to figure out the original verb. སྤྲོད་པ། གཏོང་བ། བྱེད་པ། and many more collapse into གནང་བ། That adds more arguments to my preference for not using respectful forms, since it also slows our speech. But on the other hand the person receiving the respect would feel more comfortable, so I will find a middle way.
